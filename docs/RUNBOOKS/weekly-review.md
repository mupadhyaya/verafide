# Weekly review

The founder's one recurring touchpoint under the hybrid working model (see `CLAUDE.md`). Budget
this as the primary weekly time cost — most days are unattended.

1. **Clear the "Needs Human Review" queue first.** This is the actual bottleneck; everything
   else below is lower priority than unblocking queued PRs.
2. **Skim `docs/logs/` entries from the week** for anything flagged as a blocker that didn't
   make it into a PR.
3. **Spot-check 2-3 auto-merged PRs** from the week for drift from conventions or invariants
   (cheap trust-but-verify — see `CLAUDE.md`'s Definition of Done).
4. **Re-prioritize next week's `status:ready-for-agent` set** against the current phase's exit
   criteria in `docs/BACKLOG.md`.
5. **Update `docs/BACKLOG.md`'s phase-status snapshot** and file any new issues surfaced during
   review.
